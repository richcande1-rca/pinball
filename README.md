# Pinball

A small browser-based pinball experiment built with HTML Canvas and vanilla JavaScript.

## First milestone

Start with the physics heartbeat only:

- one ball
- gravity
- solid walls
- believable bounce
- reset when the ball falls out

Flippers, bumpers, scoring, sound, tilt, and table art come later, after the ball feels right.

## Run

Open `index.html` in a browser.
